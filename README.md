# BeanCraft Artisan Roastery ☕ 

A responsive 3-page static website built for an artisanal specialty coffee brand.

 📁 Project Pages & Structure
- **`index.html` (Home Page):** Features a welcoming hero section, brand introduction, tagline, and clean navigation bar.
- **`product.html` (Product Info Page):** Showcases various artisanal coffee blends, descriptions, and pricing.
- **`order.html` (Order Page):** Contains an interactive checkout/order summary form with JavaScript validation.
- **`style.css`:** A single shared stylesheet utilizing CSS variables, warm cozy color palettes, and mobile-first responsive design.
- **`app.js`:** A single shared JavaScript file handling form validation and interactivity.

## 🌿 Git Branching & Workflow
This project strictly follows the required Git workflow using individual feature branches:
1. `home-page` (Home page development and commits)
2. `product-page` (Product page development and commits)
3. `order-page` (Order page and JS logic development and commits)
4. Final merge of all feature branches into the **`main`** branch.
